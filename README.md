# quanttide-growth

量潮增长管理

## 概述

量潮增长管理（quanttide-growth）是量潮知识管理体系中的**增长管理**领域，以管理实践方式承载增长策略制定、增长实验执行与增长效果评估。

## 领域边界

- **增长策略**：增长目标拆解、渠道策略与增长模型设计
- **增长实验**：实验设计与执行、数据观察与迭代优化
- **增长效果**：效果评估、复盘沉淀与规模化复制

> 与 media 领域的分工：本领域承载「增长管理」（策略、实验、效果），media 承载「新媒体运营」（内容与渠道执行）。
